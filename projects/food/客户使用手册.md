# 世友肉肉仓库 - 客户使用手册

## 1. 快速开始（平板电脑/iPad）

本项目支持**完全离线运行**，无需安装服务器软件，也无需网络。

1. **准备U盘**：将整个 `food` 文件夹拷贝到 U 盘。
2. **连接设备**：将 U 盘插入平板电脑。
3. **打开项目**：在文件管理器中找到并点击 `index.html`，选择使用浏览器（如 Chrome, Safari, Edge）打开即可。

## 2. 数据维护指南

你需要维护两个地方：**图片文件** 和 **数据配置文件**。

### A. 图片文件管理 (`assets/images`)

目录结构已按类别规划：
*   牛肉图： `assets/images/beef/`
*   猪肉图： `assets/images/pork/`
*   ...以此类推

**💡 图片建议：**
*   **格式**：推荐 `.jpg` 或 `.png`。
*   **尺寸**：建议宽度在 **800px - 1200px** 之间，不要太大（影响加载），也不要太小（模糊）。
*   **命名**：请使用 **英文+数字**（如 `beef_shin_01.jpg`），**切勿使用中文文件名**，否则在某些平板上可能无法显示。

### B. 产品数据配置 (`js/data.js`)

请使用文本编辑器（如 Notepad++、VS Code）打开 `js/data.js` 文件。

你会看到如下结构，每一对 `{ ... }` 代表一个产品：

```javascript
{
  "id": "unique-id-001",              // 【必填】唯一编号，不要重复
  "name": "澳洲牛腩块 2kg/袋",          // 【必填】产品名称
  "category": "牛肉",                 // 【必填】分类：牛肉/猪肉/鸡肉/羊肉/预制菜
  "cut": "牛腩块",                    // 部位
  "origin": "澳大利亚",               // 产地
  "grade": "MSA",                     // 等级
  "packaging": "2kg/袋",              // 包装
  "weightOptions": ["2kg", "16kg"],   // 重量选项
  "priceWholesale": "¥48/kg",         // 【必填】批发价
  "priceRetail": "¥58/kg",            // 【必填】零售价
  "stockStatus": "现货",               // 库存状态：现货/期货
  "thumb": "assets/images/beef/a.jpg", // 【必填】列表小图路径
  "images": [                         // 【必填】详情页大图路径（可以放多张）
    "assets/images/beef/a.jpg",
    "assets/images/beef/b.jpg"
  ]
}
```

**如何新增一个产品？**
1. 复制现有的一个 `{ ... }` 数据块。
2. 粘贴到 `products: [ ... ]` 列表的最后（注意：上一个产品的结束大括号 `}` 后面要加一个逗号 `,`）。
3. 修改里面的内容为你新产品的信息。

## 3. 常见问题 (FAQ)

**Q: 为什么图片显示不出来，是个红色的圆圈？**
A: 这说明路径不对。请检查：
1. `js/data.js` 里写的路径（如 `assets/images/...`）和实际文件夹里的文件名是否**完全一致**。
2. 文件名的大小写是否一致（`Beef.jpg` 和 `beef.jpg` 是不同的）。
3. 文件名是否包含中文或特殊符号（建议只用英文和数字）。

**Q: 打开网页全是乱码？**
A: 请确保你的浏览器编码设置为 `UTF-8`。现代浏览器（Chrome/Safari）通常会自动识别。

**Q: 修改了数据，刷新网页没变化？**
A: 
1. 请确认你修改并保存了 `js/data.js` 文件。
2. 浏览器可能有缓存，请尝试强制刷新（通常是长按刷新按钮，或清除缓存）。
