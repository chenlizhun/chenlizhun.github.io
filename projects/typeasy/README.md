# Typeasy - 儿童趣味打字练习平台规划书

## 1. 产品定位
**Typeasy** 是一款专为 6-9 岁儿童设计的 Web 端打字练习程序。
- **目标**：帮助儿童建立正确的键盘指法肌肉记忆，从零基础达到盲打水平。
- **风格**：色彩明快、交互友好、游戏化反馈、无压力学习。
- **核心理念**：指法优先 > 速度优先。

## 2. 核心功能模块

### 2.1 沉浸式练习界面 (The Stage)
- **大字号显示**：当前输入的字母以超大字号显示在屏幕中央，减少视力负担。
- **动态游标**：清晰的输入光标，指示当前进度。
- **虚拟键盘与双手 (Visual Guide)**：
  - 屏幕下方常驻虚拟键盘。
  - **关键特性**：不仅高亮按键，还要**高亮对应的是哪根手指**。对于 6-9 岁孩子，知道“用哪只手的哪个手指”比知道“按哪个键”更难。
  - 色彩编码：左手（红/粉/橙/黄/绿）与右手（青/蓝/紫...）区域严格区分。

### 2.2 渐进式课程体系 (Curriculum)
课程设计遵循“本位行 (Home Row) -> 上排 -> 下排 -> 综合”的逻辑，每课控制在 1-2 分钟。

*   **L1: 探索与热身** - 认识 F 和 J（食指定位）。
*   **L2: 本位行核心** - A S D F J K L ;
*   **L3: 食指的扩展** - G H R U T Y
*   **L4: 中指与无名指扩展** - E I C ,
*   **L5: 小指的挑战** - Shift 键、Q P Z /
*   **L6: 单词冲刺** - 简单的 CVC (Consonant-Vowel-Consonant) 单词，如 cat, dog, pig。

### 2.3 游戏化反馈系统 (Gamification)
- **即时反馈**：
  - 正确：清脆悦耳的音效（如泡泡破裂声），字符发光或变成星星飞走。
  - 错误：温和的提示音（如弹簧声），键盘上对应正确按键闪烁提示，**不使用**刺耳的蜂鸣声或红叉。
- **连击系统 (Combo)**：连续正确输入 10 次，触发火焰/彩虹特效，激励专注。
- **结算评价**：使用 1-3 星评价，而不是冷冰冰的分数。

## 3. 技术架构规划

为了保证高性能和良好的扩展性，项目采用现代原生 Web 技术栈：

*   **结构 (HTML5)**：语义化标签，Canvas 用于粒子特效。
*   **样式 (CSS3)**：
    *   Flexbox/Grid 布局。
    *   CSS Variables 定义主题色，方便后期换肤（如“护眼模式”、“糖果模式”）。
    *   CSS Animations 处理按键按下、回弹等微交互。
*   **逻辑 (JavaScript ES6+)**：
    *   **模块化设计**：
        *   `GameEngine`: 控制游戏循环、状态（开始、暂停、结束）。
        *   `KeyboardRenderer`: 处理虚拟键盘渲染和高亮逻辑。
        *   `LessonManager`: 管理课程数据和进度。
        *   `SoundManager`: 处理音效（使用 Web Audio API 获得低延迟）。
    *   **无框架依赖**：保持轻量，直接操作 DOM 或使用简单的响应式状态代理。

## 4. UI/UX 设计草案
- **主色调**：天空蓝 (#4ECDC4) 搭配 暖黄 (#FFE66D) 和 活力红 (#FF6B6B)。
- **字体**：`Nunito` (圆体) 用于 UI，`Roboto Mono` 或 `Courier Prime` 用于练习文本（区分 l 和 1, O 和 0）。
