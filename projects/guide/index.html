Introduction

This design system provides a collection of reusable components, guidelines, and assets used across our projects (Typeasy, Pixeldraw, etc.). It ensures consistency in visual design and interaction patterns, making our tools professional yet approachable for children.

Design Principles

  • Child-Friendly: Use rounded corners, soft shadows, and vibrant colors.
  • Clear Feedback: Every action should have an immediate visual or auditory response.
  • Simplicity: Avoid clutter. Focus on the core task.
  • Accessibility: Ensure high contrast and clear typography.

Quick Start

To use this design system in your project, simply include the CSS file in your HTML <head>:

<!-- Add Fonts -->
<link href="https://fonts.googleapis.com/css2?family=Nunito:wght@400;700;800&family=Roboto+Mono:wght@500;700&display=swap" rel="stylesheet">

<!-- Add Design System -->
<link rel="stylesheet" href="../guide/css/design-system.css">
