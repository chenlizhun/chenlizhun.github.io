# EduTogether 家庭积分管理系统使用手册

欢迎使用 **EduTogether** 家庭积分管理系统！本系统旨在通过积分激励的方式，帮助家长记录孩子的成长点滴，培养良好的行为习惯。

本手册分为两个主要场景：
1.  **管理场景**：家长通过手机进行日常操作。
2.  **展示场景**：通过家里的电脑、iPad或闲置大屏手机展示实时积分。

---

## 场景一：管理场景 (手机端/家长)

家长主要使用手机浏览器或微信访问本系统，进行积分的授予、扣除以及家庭成员管理。

### 1. 注册与登录
*   **创建家庭**（首次使用）：
    *   点击“创建新家庭”。
    *   **家庭名称**：给自己家起个好听的名字（全局唯一）。
    *   **管理员PIN码**：设置一个4-6位的数字密码。**重要**：此密码用于添加成员、修改设置等敏感操作，请牢记。
    *   **您的昵称**：如“爸爸”、“妈妈”。
*   **加入家庭**（其他成员）：
    *   点击“加入现有家庭”。
    *   输入**家庭ID**（由创建者提供，在“设置”页可见）。
    *   输入**管理员PIN码**。
    *   设置自己的昵称。

### 2. 日常加减分 (✨ 加减分)
这是您最常用的功能，用于记录孩子的行为。
1.  点击底部导航栏的 **“加减分”** (✨)。
2.  找到对应的孩子卡片。
3.  **选择模式**：
    *   **🌟 奖励**：用于增加积分（如：做家务、作业优秀）。
    *   **🎁 支出**：用于扣除积分（如：兑换礼物、看电视时长）。
4.  **选择/输入理由**：
    *   点击预设的标签（如“阅读”、“运动”）。
    *   也可以直接在输入框输入具体原因。
    *   *提示：点击“+ 添加”可自定义常用标签；点击“- 删除”可管理现有标签。*
5.  **点击分值**：点击下方的数字按钮（如 `+1`, `+5`, `-10` 等）即可完成操作。

### 3. 查看报表 (📊 报表)
*   点击底部导航栏的 **“报表”** (📊)。
*   这里记录了所有的积分变动流水，包含：时间、孩子姓名、变动分值、原因以及操作人。
*   用于复盘和核对记录。

### 4. 系统设置 (⚙️ 设置)
*   **孩子管理**：
    *   **添加孩子**：输入孩子昵称、性别（影响主题色）和初始积分。
    *   **修改昵称**：点击孩子名字后的编辑图标。
    *   **修正总分**：如果总分有误，可直接修改当前总积分（系统会记录为“管理员修正”）。
*   **家庭信息**：
    *   查看**家庭ID**（用于邀请家人）。
    *   修改家庭名称。
    *   修改管理员PIN码。
*   **退出登录**：安全退出当前账户。

## 场景二：展示场景 (电脑/iPad/电视)

展示场景作为一个“激励看板”，通常放置在客厅或书房，让孩子随时能看到自己的积分进度。

### 1. 进入大屏模式
1.  使用电脑、iPad或智能电视的浏览器访问本系统网址。
2.  登录您的家庭账号。
3.  点击底部导航栏的 **“展示”** (📺)。
4.  系统将进入**海报视图**模式，界面会自动全屏化并隐藏无关菜单。

### 2. 功能特点
*   **大屏视觉优化**：
    *   采用超大字体显示积分。
    *   根据孩子性别自动区分粉色/蓝色主题。
    *   多孩子家庭会自动排版（行/列布局）。
*   **⚡️ 实时同步**：
    *   **无需刷新**：当家长在手机端修改了分数，展示大屏会在 **3秒内** 自动更新。
    *   **动画反馈**：分数变化时会有数字跳动效果，增强激励感。

### 3. 最佳实践
*   推荐使用 **iPad** 或 **闲置的显示器** 常亮显示。
*   可以将浏览器设置为全屏模式（F11），获得最佳沉浸体验。

### 常见问题 (FAQ)

*   **Q: 忘记PIN码怎么办？**
    *   A: PIN码存储在云端，如果忘记，目前需要联系系统管理员重置或重新创建家庭。请务必妥善保管。
*   **Q: 体验模式的数据会保存吗？**
    *   A: 不会。体验模式的数据存储在本地临时内存中，刷新页面或关闭浏览器后即丢失。请务必注册正式家庭账号使用。
*   **Q: 多个家长可以同时管理吗？**
    *   A: 可以。只要使用相同的家庭ID和PIN码登录，所有家长的操作都会实时同步。
